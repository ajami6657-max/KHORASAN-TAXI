# تاکسی اینترنتی خراسان | KHORASAN TAXI

سامانه حمل‌ونقل هوشمند برای **خراسان رضوی، خراسان شمالی و خراسان جنوبی**.

> هدف این مخزن ساخت محصول واقعی، امن و قابل توسعه است. قابلیت‌هایی که هنوز به سرور یا سرویس بیرونی متصل نشده‌اند، آزمایشی هستند و هرگز سفر یا پرداخت واقعی را وانمود نمی‌کنند.

## اجزای محصول
- Passenger Android: اپلیکیشن مسافر
- Driver Android: اپلیکیشن راننده
- Admin Panel: پنل مدیریت
- Backend API: احراز هویت، سفر، قیمت‌گذاری، پرداخت و موقعیت
- AI Assistant: دستیار فارسی با قابلیت راهنمایی عمومی آفلاین
- Maps: نقشه، مکان‌یابی و مسیریابی

## محدوده جغرافیایی
| استان | نمونه شهرها |
|---|---|
| خراسان رضوی | مشهد، نیشابور، سبزوار، تربت‌حیدریه، قوچان |
| خراسان شمالی | بجنورد، شیروان، اسفراین، آشخانه |
| خراسان جنوبی | بیرجند، قائن، طبس، فردوس، نهبندان |

فهرست شهرها باید قابل مدیریت باشد. فعال‌شدن سفر در هر شهر به پوشش راننده، پشتیبانی و مجوزهای لازم وابسته است.

## فناوری پایه
- Android: Kotlin + Jetpack Compose
- Backend (مرحله بعد): API مستقل + PostgreSQL
- Realtime (مرحله بعد): WebSocket
- CI: GitHub Actions

## ساخت APK آزمایشی
با هر commit روی `main`، گردش‌کار Android CI تلاش می‌کند نسخه Debug را بسازد. APK در بخش Artifacts همان اجرای GitHub Actions قرار می‌گیرد.

## وضعیت فعلی
مخزن در مرحله اسکلت اولیه اندروید و مستندات معماری است. درخواست سفر، پرداخت، GPS زنده و اتصال سرور تا زمان پیاده‌سازی و آزمایش یکپارچه، عملیاتی محسوب نمی‌شوند.

## امنیت
- کلید API، رمز عبور و کلید امضای انتشار را در Git ثبت نکنید.
- اطلاعات هویتی رانندگان باید امن و با دسترسی محدود نگهداری شود.
- پرداخت واقعی فقط پس از اتصال درگاه معتبر و آزمون امنیتی فعال می‌شود.
