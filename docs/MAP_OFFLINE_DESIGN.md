# طراحی نقشه آفلاین KHORASAN TAXI

## تصمیم فنی
- موتور نمایش نقشه: MapLibre Native Android.
- قالب داده: نقشه برداری (Vector Tiles)؛ مناسب‌تر برای انتخاب محدوده و ذخیره محلی نسبت به تصاویر نقشه.
- منبع اولیه آزمایشی: OpenFreeMap با style URL زیر:
  `https://tiles.openfreemap.org/styles/liberty`
- منبع داده نقشه OpenStreetMap است؛ نام و منبع داده باید در رابط نقشه قابل مشاهده باشد.
- نقشه و دانلودهای آن باید قابل تعویض باشند تا برنامه به یک میزبان ثابت وابسته نماند.

## محدودیت‌های استفاده از منبع اولیه
- طبق شرایط فعلی OpenFreeMap، هر دانلود آفلاین حداکثر ۳۰۰۰ کاشی یا ۵۰ مگابایت است (هرکدام زودتر برسد).
- حداکثر ۴ درخواست هم‌زمان برای دانلود مجاز است.
- درخواست‌ها باید User-Agent یکتایی داشته باشند که برنامه KHORASAN TAXI را مشخص کند.
- انتساب داده باید نمایش داده شود: «OpenFreeMap © OpenMapTiles • داده‌ها از OpenStreetMap».
- سرویس عمومی SLA تضمین‌شده ندارد؛ دسترسی از شبکه‌های ایران باید پیش از انتشار و در چند اپراتور آزمایش شود.
- از tile.openstreetmap.org برای دانلود پیش‌دستانه یا بسته آفلاین استفاده نمی‌کنیم؛ سیاست آن دانلود انبوه و آفلاین‌سازی را ممنوع می‌کند.

## تجربه کاربر
1. کاربر استان و شهر را انتخاب می‌کند.
2. در بخش «نقشه‌های آفلاین»، محدوده‌های کوچک و قابل دانلود را می‌بیند.
3. حجم تخمینی و سقف بسته قبل از دانلود نمایش داده می‌شود.
4. دانلود با حداکثر ۴ درخواست هم‌زمان، نوار پیشرفت، توقف و ادامه انجام می‌شود.
5. بعد از تکمیل، نقشه بدون اینترنت باز می‌شود.
6. کاربر با لمس نقشه، نشانگر مبدأ یا مقصد را جابه‌جا می‌کند؛ مختصات دقیق ذخیره می‌شود، حتی اگر نام روستا در جست‌وجو نباشد.
7. نشانی متنی و مختصات دستی فعلی همیشه به‌عنوان مسیر جایگزین باقی می‌مانند.

## مراحل پیاده‌سازی
- [ ] افزودن SDK رسمی MapLibre Native Android و مجوز اینترنت فقط برای بارگیری نقشه.
- [ ] ساخت صفحه نقشه با چرخه عمر صحیح MapView در Compose.
- [ ] نمایش سبک Liberty و انتساب منبع روی نقشه.
- [ ] نمایش نشانگر انتخابی و بازگرداندن مختصات به فرم مبدأ/مقصد.
- [ ] پیاده‌سازی مدیریت بسته آفلاین با OfflineManager و مشاهده وضعیت/حجم دانلود.
- [ ] اعمال سقف ۳۰۰۰ کاشی یا ۵۰ مگابایت و حداکثر ۴ درخواست هم‌زمان.
- [ ] تست دانلود، بستن برنامه، راه‌اندازی مجدد و نمایش در حالت Airplane Mode.
- [ ] تست دسترسی سرویس از اینترنت همراه و ثابت در ایران؛ در صورت عدم دسترسی، طراحی میزبان جایگزین یا بسته نقشه خودمیزبان.

## معیار پذیرش
- نقشه پس از دانلود کامل در حالت Airplane Mode نمایش داده شود.
- لمس نقشه مختصات معتبر مبدأ/مقصد را در پیش‌نویس محلی ذخیره کند.
- نبود اینترنت یا شکست دانلود، ورود دستی نشانی و مختصات را مختل نکند.
- هیچ دانلودی از سقف مجاز ارائه‌دهنده عبور نکند.
- قبل از تکمیل بسته، برنامه ادعای «نقشه آفلاین آماده» نکند.
